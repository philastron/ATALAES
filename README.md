# ATALAES
ATALAES represents an end-to-end pipeline for the fully automated analysis of UV QSO absorption spectra, optimized for z&lt;0.5. It has been developed to the study intervening and associated QSO absorption-line systems in the low-redshift IGM and CGM.

<img width="2282" height="1311" alt="atalaes" src="https://github.com/user-attachments/assets/b342934a-c555-4809-b411-822ccd292478" />

ATALAES is programmed in the ESO-MIDAS command language, as it uses many of the MIDAS sub-routines.
